# Coverage checklist

What a complete strategy covers. Not every product needs every line: write "not applicable" with a reason rather than skipping silently.

## Search acquisition
- **Keyword research**: seeds from the product's real capabilities, tasks, file types, problems, comparisons and alternatives; geographies and languages from the baseline.
- **Search intent**: informational, navigational, commercial, transactional; checked against what ranks, not guessed from words.
- **Topic clusters**: one primary keyword per page; variants (sizes, formats, synonyms) on the same page unless the SERP shows separate intents.
- **Landing-page roadmap**: new pages only where intent is unserved; each maps to a cluster and a roadmap item. Avoid doorway pages (many near-identical pages that differ by one word).
- **Content strategy**: unique instructions, examples, limits, FAQs written for users; guides that answer the questions around the tool.
- **Internal linking**: related tools, hubs, footer and navigation; no orphan pages.
- **Technical SEO**: indexability, sitemap, canonicals, titles and headings, structured data appropriate to the page type, page speed signals. Rendered-page checks belong to experience-audit.

## Distribution
- **Communities** (for example Reddit, Quora, Stack Exchange, niche forums): where the audience asks the problem; read and cite each community's self-promotion rules.
- **Social distribution** (for example Pinterest, YouTube, short video): only where the output is visual or teachable.
- **Brand-first anonymous presence**: participate as the brand with disclosed affiliation; no personal or fake accounts, no vote manipulation, no undisclosed promotion.
- **Directories**: tool directories and listings with their submission rules and costs; submissions are done by the user after approval.
- **Backlinks**: earned through useful pages (resource pages, educators, complementary tools); never bought or exchanged schemes.
- **Partnerships**: complementary products, newsletters, communities; what each side gains.

## Measurement
- **Search Console**: verified property, sitemap submitted by the owner, monthly query export for `refresh`.
- **Analytics (for example GA4)**: events for the core actions (start, success, error, download or signup) with page context.
- **Referral sources**: UTM conventions per channel.
- **Landing-page performance**: impressions, clicks, CTR, position per page; engagement per page.
- **Tool usage funnel**: landing view to completed action.
- **Conversion and retention indicators**: returning users, repeat use, signups; within what consent allows.

## Monetization readiness
- **Ad network readiness (for example AdSense)**: original, useful content beyond the tool widget; clear navigation; policy pages; no prohibited content; traffic that is not incentivised.
- **Content quality**: thin or template pages are a risk for both rankings and ad approval.
- **User experience**: ads must not displace the core task, cause layout shift or break mobile use.
- **Privacy and consent**: privacy policy, a consent solution where required (for example a certified consent management platform for EEA and UK users), ads.txt; cite the current policy pages.
- **Ad placement trade-offs**: placements versus task completion and page speed; start conservative and measure.
- For subscription or other models: what the model needs from growth (signups, activation) instead of ad sections.
